# Smart Work Environment

## Description
This project simulates a smart environment that processes different types of tasks:
- Email processing
- Data cleaning
- Task scheduling

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the project:
   python inference.py

## Output Example

{'result': 'Processed email: Hello', 'score': 1.0}
{'result': 'Cleaned data: [1, 2, 3]', 'score': 1.0}
{'result': 'Scheduled Meeting at 10 AM', 'score': 1.0}
